# 설계: 서브 관리자 · 메뉴 순서 · 아카이브 · 특별행사 콘텐츠 · 회원 접근

작성일: 2026-06-16

새서울 CBMC 운영앱(cbmc-app)에 5개 기능을 추가/개편한다. 권한 모델(①)이 ⑤의 토대이므로
순서를 ②→①→⑤→④→③로 진행한다(쉬운 것 → 큰 것, 한 번에 하나씩).

---

## ① 서브 관리자 — 메인 보호 + 서브 지정

현재: 권한 3단계(admin/member/guest = 임원/회원/관심). `/roles`에서 **아무 임원이나** 누구든
권한 변경 가능 → 메인 관리자도 강등 위험. "메인 vs 서브" 구분 없음.

변경:
- `profiles`에 `is_owner boolean default false` 추가. onjulyeo@gmail.com = `true`(메인, 영구 보호).
- **역할(role) 변경은 메인만** 가능. RLS: `profiles.role`/`is_owner` UPDATE는 메인(is_owner)만.
  - 메인 본인의 role·is_owner는 누구도(본인 포함 화면상) 못 내림.
- `/roles` 페이지·메뉴는 **메인에게만** 노출. 서브 임원·회원에겐 숨김(접근 시 차단 문구).
- 서브 임원은 운영 기능(회원·출석·회계·콘텐츠·일정·공지·아카이브)은 그대로 전부 사용.

판정 함수: `is_owner()` SQL 함수(security definer, RLS 재귀 회피) 추가. `is_admin()`은 유지.

## ② 메뉴 순서 — 주제별 묶음

`SiteNav.tsx` ADMIN 메뉴를 그룹 순서로 재배치(가로 메뉴, 그룹 사이 옅은 구분선):

- **운영**: 대시보드 · 공지 · 콘텐츠
- **모임**: 연간일정 · 출석식대 · 출석통계
- **관리**: 회원관리 · 회계 · 아카이브
- (메인만): 역할관리

회원(MEMBER) 메뉴: 공지(홈) · 회원명단 · 아카이브 (⑤에서 추가).

## ③ 아카이브 — 카테고리 정리 + 앱 업로드 (사용자가 단순화 결정)

현재: 분류 5개(연혁·역대회장·사진·문서·기타) 카드 그리드. RLS read=로그인 누구나, write=admin.
업로드 기능(사진+제목+날짜+내용+링크, 임원만)은 **이미 존재**.

> 결정 변경: 연표/역대임원/앨범 같은 신규 기능 대신 **카테고리만 정리 + 기존 앱 업로드 활용**.

- 분류를 `연혁·역대임원·행사사진·영상·문서·기타`로 교체.
- **영상**: 중앙회 CBMC 소개영상 등 링크용 → 카드에서 "▶ 영상 보기" 표시.
- 업로드는 기존 그대로. `archive.category`는 제약 없는 text → SQL 불필요.

## ④ 콘텐츠 — 특별행사 탭 추가

현재: `ContentHub` 탭 2개(주간 포스터 / 경조사 안내).

- 3번째 탭 **특별행사** 추가(OccasionTool과 유사한 폼 기반 생성기).
- 행사 종류별 템플릿: 한국대회 · 송년회 · 봄소풍 · 수련회 · 기타.
- 입력: 행사명 · 일시(여러 날 가능) · 장소 · 참가비 · 신청/마감 · 준비물 · 교통/차량 · 추가내용.
- 결과: **카톡 공지글** 자동 생성 + 복사. 포스터는 기존 PosterEditor 재사용(별도 생성 안 함).

## ⑤ 회원 접근 — 명단(제한)·아카이브 열기

현재: 회원 메뉴 = 공지 1개. `members` 테이블 RLS=임원만(회원은 못 봄).

- **회원 명단(제한)**: Postgres VIEW `members_directory`(이름·연락처·회사만) 생성.
  - 뷰는 authenticated에 SELECT 허용, anon revoke. 전체 `members` 표는 임원 전용 유지.
  - 회원용 `/directory` 페이지(읽기 전용, 이름·연락처·회사). 검색 가능.
- 회원 메뉴에 **회원명단 · 아카이브** 추가. 아카이브는 RLS상 이미 회원 읽기 가능(write만 admin).
- "주차 모임안내"는 회원 홈의 '이번 주 모임' 1개 유지(추가 페이지 없음).
