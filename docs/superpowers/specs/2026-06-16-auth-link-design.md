# 설계: 권한·로그인 개편 (A안 — 카카오 + 관리자 연결)

작성일: 2026-06-16

회원이 카카오로 로그인하고, 메인 관리자가 그 로그인 계정을 명단 회원과 **연결**하면서
권한(운영진/회원/관심)을 지정한다. 이메일이 채워진 회원은 로그인 시 **자동 연결**된다.

## 배경 (현재)
- 로그인: 매직링크(이메일) + 카카오. 둘 다 `auth.users`+`profiles`(role 기본 guest) 생성.
- 권한: `profiles.role` (운영진=admin / 회원=member / 관심=guest), 변경은 메인(owner)만.
- `members`는 별도 테이블(이미 `email` 칸 있음, 대개 비어 있음). profiles↔members 연결 없음.
- 카카오 제약: 이메일은 "선택 동의"(안 줄 수 있음), 전화는 비즈앱 심사 필요 → 자동 식별 불가.

## 설계

### 1. 데이터 (마이그레이션 0026)
- `profiles.member_id uuid references members(id)` (nullable) — 로그인 계정 ↔ 명단 회원 연결.
- `members.email` 그대로 사용(명단에서 입력·수정).
- `handle_new_user` 트리거 보강: 새 로그인 시 이메일이 명단 회원과 같으면
  `profiles.member_id` 자동 설정 + `role='member'`(guest일 때만). 이메일 없으면 guest 유지(관리자 수동 연결).

### 2. 로그인 (#7)
- 회원=카카오 버튼(기존), 메인·운영진=매직링크도 유지.
- 로그인 폼에 **이메일 자동저장**(localStorage)으로 재방문 시 자동 채움.
- 세션은 수 주 유지(쿠키+refresh) — "매번 로그인" 필요 없음. 화면에 안내 문구.

### 3. 권한설정 화면 개편 (`/roles`, 메인 전용)
- **미연결 로그인** 섹션: `member_id`가 비고 owner가 아닌 사람 → 닉네임·이메일 표시.
  - "명단의 누구?" 회원 선택(검색 드롭다운)으로 **연결**. 카카오 이메일이 명단 이메일과
    같으면 그 회원을 **자동 추천**(원클릭).
  - 연결과 함께 권한(운영진/회원/관심) 지정.
- **연결됨** 섹션: 연결된 사람 → 권한 변경 / 연결 해제. (메인 본인은 잠금 유지)

### 4. 회원 명단 (드로어)
- **이메일 입력칸** 추가(편집). "로그인 연결됨 / 미가입" 배지 표시.

### 5. 메인(owner)
- onjulyeo는 안전하게 매직링크로 메인 유지(카카오는 보조). is_owner 보호 그대로.

## 비고 / 제약
- 민감정보 저장 금지 원칙 유지(이메일은 연락 식별용, 주민번호·계좌 없음).
- 카카오 전화번호 매칭은 비즈앱 심사 필요 → 채택 안 함(이메일 또는 수동 연결).
- SQL은 사용자가 Supabase SQL Editor에서 실행(기존 워크플로). 배포는 코드 변경분만.
- 향후(미룸): 회원 본인 정보 수정 요청, 다지회 chapter 분리.
