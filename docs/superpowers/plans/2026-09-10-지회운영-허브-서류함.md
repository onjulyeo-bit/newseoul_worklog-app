# 지회 운영 허브 + 서류함 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "서명" 독립 탭을 없애고 "운영매뉴얼" 탭을 **지회 운영** 허브(`/ops`)로 확장해 매뉴얼 + 서류함(전자서명 · 보관 서류)을 한곳에 모은다. 보관 서류는 서명 완료본 자동 노출 + 운영진 직접 업로드.

**Architecture:** 서버 페이지(권한 게이트 + 로더) → 순수 View 컴포넌트, `.moim-ops` 스코프 CSS 주입(기존 매뉴얼 카드 스타일 이식). 업로드 파일은 서명 모듈과 같이 DB base64(`chapter_docs.file_data`)에 저장하고 `GET /api/docs/[id]`가 관리자 세션(RLS)으로 스트리밍. service_role 미사용. 마이그레이션은 수동 적용이므로 코드는 테이블 부재 시 0건/안내로 견딘다.

**Tech Stack:** Next.js 16(App Router, async params), React 19, Supabase(RLS `is_staff()`/`is_admin()`), lucide-react. 테스트 스위트 없음 → `npm run build` + 프리뷰 셸 스크린샷이 게이트.

**Spec:** `docs/superpowers/specs/2026-09-10-지회운영-허브-서류함-design.md`
