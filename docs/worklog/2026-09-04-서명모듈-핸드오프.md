## 2. 확정된 결정 (대화에서)
- **service_role 키 미사용** (사용자 .env.local 원칙). 원본 PDF·서명 PNG는 DB(base64)에 보관, 서명자 접근은 토큰 게이트 SECURITY DEFINER RPC만. anon 스토리지 정책은 파일 열거 가능 → 부적합.
- **최종 PDF 저장 안 함** — 볼 때마다 즉시 합성(`/api/sign/pdf/[id]` 관리자 / `/api/sign/[token]/pdf` 서명자 본인). 추가 마이그레이션·저장소 불필요.
- **완료 서류함 = A안** — `/sign` '완료' 탭에 영구 보관, 운영진+읽기운영진만. 회의록 등으로 넓히려면 나중에 별도 메뉴(C안).
- 관리자 경로 `/sign` (사양서의 `/admin/sign` 대신 — 이 앱은 `/admin/` 접두어 없음). 서명자 링크 `/s/[token]` 은 메뉴 없음, 로그인 없음.
- 한글 폰트 Pretendard **TrueType**(`lib/fonts/Pretendard.ttf`) — static OTF는 @pdf-lib/fontkit "Not a CFF Font". `next.config` outputFileTracingIncludes로 함수 번들.
- 서명자 본인 서명본엔 **본인 서명만** 합성(다른 서명자 서명 미포함). 전체본은 관리자 현황판.
